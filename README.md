# DigiBank
A console-based banking and ATM simulation system developed in C, featuring account management, PIN authentication, deposits, withdrawals, fund transfers, transaction history, and account deletion.
#ABOUT THE PROJECT

The Mini Banking & ATM Simulation System provides a simple interface for managing bank accounts and performing essential banking operations. Users can create accounts, securely access their accounts using a PIN, check balances, deposit and withdraw money, transfer funds, and view transaction records.

The system also includes account deletion functionality, allowing inactive accounts with zero balance to be removed from active account records.

#FEATURES

Account Creation: Create new bank accounts with automatically generated unique account numbers.

Account Search: Search for an account using its account number.

Account Management: Display all active bank accounts.

ATM Authentication: Access banking services using an account number and PIN, with a limited number of login attempts.

Balance Inquiry: Check the available account balance.

Deposit Money: Add money to an existing account.

Withdraw Money: Withdraw money with balance verification and a daily withdrawal limit.

Fund Transfer: Transfer money between two active accounts.

Transaction History: View recorded deposits, withdrawals, and transfers.

Mini Statement: Display the five most recent transactions.

PIN Management: Change the account's existing PIN.

Account Deletion: Delete an account after verifying that its balance is zero.

Banking Statistics: Display the total number of active accounts, combined account balance, and transaction count.
